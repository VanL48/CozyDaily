# CozyDaily v1.0 — Personal Website Starter

A cozy personal productivity dashboard made with plain HTML, CSS and JavaScript.

## How to open it

1. Download and extract `cozydaily-v1.zip`.
2. Open the extracted `cozydaily-v1` folder in VS Code.
3. Open `index.html`.
4. Recommended: install the **Live Server** extension in VS Code.
5. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to open it in a browser.

## What's included

- Dashboard page
- Planner page: add, complete and delete tasks
- Habits page: add, complete and delete habits
- Journal page: choose a mood and save an entry
- Settings page: light, dark and system themes
- Responsive layout for desktop and mobile
- Browser localStorage to keep demo data and theme preference on this device

## Project files

- `index.html` — page content and layout
- `css/styles.css` — colours, typography, layout and responsive styling
- `js/app.js` — navigation, theme switching and interactive features
- `assets/` — place your images and other assets here

## Important notes

- You do **not** need Java. This project uses JavaScript, which is different from Java.
- There is no backend, login system or cloud database yet.
- Tasks, habits, journal entries and theme settings are saved only in this browser on this device.
- Clearing browser site data may remove the saved demo data.
- Google Fonts are loaded online; fallback fonts are used if you are offline.

## Good first things to customize

1. Change the welcome message in `index.html`.
2. Try changing the CSS colour variables at the top of `css/styles.css`.
3. Add your own starter habits in `defaultData` inside `js/app.js`.
4. Explore how `renderTasks()` updates the task list.

Have fun making it yours!
